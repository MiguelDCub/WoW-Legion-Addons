# WoW Legion Addons

A collection of independent addons and utilities for **World of Warcraft: Legion 7.3.5** (interface `70300`).

## Published addons

| Addon | Description | Version |
| --- | --- | --- |
| [LegendarySetFix](LegendarySetFix/) | Safely switch saved Equipment Sets that use different legendary items. | v1.4 |
| [TrinketTracker](TrinketTracker/) | Movable visual tracker for equipped trinkets, buffs and cooldowns. | v1.2.1 |

## Planned additions

The following projects are being prepared for publication: **GearScan**, **RotationScan**, and **FireCursor**. They will each have their own folder and documentation once their installed versions have been checked.

## Installation

Open the folder for the addon you want, and place that **individual addon folder** inside your game's `Interface/AddOns/` directory. Each folder has its own README with installation, commands and limitations. You do not need to install all addons.

## Compatibility

- Game client: **WoW Legion 7.3.5**
- Interface: **70300**
- Community projects; not affiliated with or endorsed by Blizzard Entertainment.
